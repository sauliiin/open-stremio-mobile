## NuvioMobile

Parts of OmniStream's refreshed interaction and visual design were adapted
from ideas and implementation patterns in
[NuvioMobile](https://github.com/NuvioMedia/NuvioMobile), inspected at commit
`b80ee5ab8a550f1385c438071694a51ed3b0ef00`.

The adapted work includes the floating translucent navigation pattern,
scroll-responsive navigation labels, glass-like surfaces, responsive settings
navigation, loading skeletons and shared spacing/motion tokens. The code was
rewritten and integrated with OmniStream's own colors, themes, data model,
navigation graph and touch/D-pad behavior.
